# 🎓 PNG Uni Hub — Interactive University Information Kiosk

An interactive multimedia web application developed as part of the **IT0305 – Graphics and Multimedia** assessment. This platform provides comprehensive information about **8 universities in Papua New Guinea**, including programs, tuition fees, entry requirements, facilities, and campus media.

## ✨ Features

| Feature | Description |
|---------|-------------|
| **Homepage** | Hero section, problem/solution, partner university carousel |
| **Universities Listing** | Grid of all 8 universities with gradient cards |
| **University Details** | Courses, tuition fees, entry requirements, video, gallery |
| **Gallery** | 3D rotary carousel + split grid view of campus images |
| **Admin Dashboard** | Upload videos, images, audio, and logos |
| **Multimedia Playback** | Background music + autoplay video on hover/click |
| **Responsive Design** | Works on desktop, tablet, and mobile devices |

## 🚀 How to Run the System

### Prerequisites
- Python 3.12 or higher
- XAMPP (for database, if applicable)
- VS Code or any code editor

### Steps

1. **Clone or download the repository**

2. **Open the terminal** in the project folder:
   cd PNG-University-Guide

3. **Install dependencies:**
   python -m pip install flask flask-cors

4. **Run the application:**
   python app.py

5. **Open in browser:**
   http://localhost:5000
